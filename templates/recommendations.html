Rendering

Critical Raven renderer — SVG rewrite for mobile + retina
Current pipeline: OpenCV numpy arrays at IMAGE_SIZE=160px → PNG → CSS scaled to 150px. Non-integer scale ratio (0.9375×) with image-rendering: pixelated causes irregular pixel rows. On mobile, the 480px fixed grid overflows 375px viewports. Retina screens (2×/3× DPR) make PNG sources look soft.

Recommended fix: Rewrite rendering.py shape logic as SVG. Server returns JSON shape descriptors; frontend renders as inline <svg>. Resolution-independent, responsive, tiny payload, zero scaling artifacts at any DPR.
  • SVG (recommended): ~200 lines JS, rewrite shape drawing. Perfect everywhere.
  • 480px render + responsive CSS: Change IMAGE_SIZE=480, use percentage-based grid. Good enough on most devices, no rewrite.
  • 160px display at 160px CSS: Easiest fix for desktop only; doesn't solve mobile.

New Puzzle Types

Idea Color-based abstract matrix generator
I-RAVEN and PGM both use grayscale fill as their "color" attribute. No published color-first RPM generator found.

Recommended approach: Extend the PGM generator to use HSL hue as a primary rule attribute — hue progressions, color XOR/AND rules across the matrix. All the rule machinery already exists; swap grayscale values for hue values in rendering. Would produce visually distinct, vibrant puzzles with color as the core reasoning dimension.
Queued Integrate Reasoning-Gym (40+ verbal/logic puzzle types)
pip install reasoning-gym — Apache 2.0. Covers knights & knaves, syllogisms, propositional logic, word ladders, cryptarithmetic, number sequences, zebra puzzles, and more. Each task type becomes a separate generator mode. Integration effort: low.

Start with: knights_knaves, zebra_puzzles, syllogisms, propositional_logic, word_ladder.
Queued CLadder — causal & counterfactual reasoning
github.com/causalNLP/cladder — MIT. Pearl's causal hierarchy (Rungs 1/2/3): association → intervention → counterfactual. Unique cognitive skill not covered by any existing puzzle type. Expert human accuracy ~85% — real depth ceiling.
Queued StepGame — text-only multi-hop spatial reasoning
github.com/ZhengxiangShi/StepGame. "A is upper-left of B. B is above C. Where is A relative to C?" No images — pure language spatial inference. k=1–10 hop depth. 50K pre-generated items available.
Queued ZebraLogic — constraint satisfaction logic grid
Python generator with z3-solver backend (pip install z3-solver). 2×2 (trivial) → 6×6 (very hard). Interactive grid fill UI needed — similar complexity to Simon Tatham integration. 1K starter set at allenai/ZebraLogicBench.
